# Mein Portfolio

Meine persönliche Portfolio-Website mit Informationen über mich, meinen Lebenslauf und meine Kontaktmöglichkeiten.

## Inhalte

- `index.html` – Startseite und Überblick über mich.
- `about.html` – Informationen über mich und meinen bisherigen Weg
- `contact.html` – Kontaktmöglichkeiten
- `style.css` – Gestaltung und responsives Layout
- `docs/` – ergänzende Dokumente(Lebenslauf)

## Website ansehen

[Mein Portfolio öffnen](https://yan-p21.github.io/Portfolio-aktuell/)

## Lokal öffnen

Repository herunterladen oder klonen und `index.html` im Browser öffnen.
